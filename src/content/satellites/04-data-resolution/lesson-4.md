What is the precision we need to capture to distinguish differences in our data? The radiometric resolution of a sensor determines the precision of the measurement.



<p>The pixels that compose raster images store numerical values that correspond to the visible wavelength they represent. For example, in an image of a zebra, the black stripes would be visualized by black pixels containing a value of 1, while the white stripes would be visualized by white pixels containing a value of 0. An image with only black and white values is referred to as a 1-bit image, where only two values are displayed.</p>



<p>As the bit number increases, the amount of variation displayed in the image increases. The bit number acts as an exponent to the number of two. A 2-bit image would contain 4 values (2^2=4). likely consisting of white, light gray, dark gray, and black. An 8-bit image would contain 256 values (2^8=256). Higher bit numbers can detect more subtle variations in light reflectance.</p>
