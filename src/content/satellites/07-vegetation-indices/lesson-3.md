Two-dimensional images consist of pixels, each with an X and Y coordinate position. When special sensors or processing techniques are used, a third dimension can be added to the data captured by sensors on satellites. This third dimension adds a Z coordinate. This third dimension can be captured using LiDAR data that determines the distance between the sensor and the object of interest. Photogrammetry is a technique that can be used to extract the Z coordinates from images of the same area captured from different angles.

<p>A point cloud is a set of points with these X, Y, and Z coordinates arranged in a 3-dimensional space to represent an object of interest. Point clouds can be used for capturing height and dimensions of objects, topographic mapping, and many other applications. The data captured using the Pléiades Neo satellite can be used to create point clouds because the sensors on the satellite capture data of the same area from multiple different angles.</p>
