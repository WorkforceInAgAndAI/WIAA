Further analysis steps can include complex calculations, visual review, or both. Because the wavelengths reflected by each object are represented as a pixel value, these values can be extracted, averaged, and analyzed. In a plot, multiple pixels capture the plot and therefore can be averaged together to create a single value for each plot.

<p>Temporal trends can also be detected and analyzed using data collected from satellites. Farmers can review historical trends in data to determine optimum treatment options for precision applications.</p>

<p>Patterns and textures can be used in analysis to interpret features of an image. An image can be differentiated into plants and soil because of the different textures and patterns of plants compared to soil.</p>

<p>Scale is a vital consideration as well, as it provides a reference to the ground truth of objects of interest. This is important when designing trials or analyzing images because it provides viewers with a reference of comparison.</p>

<h3>Atmospheric Scattering</h3>
<p>When light travels through Earth's atmosphere on its way to a satellite sensor, it can be scattered by particles in the air. Different sizes of particles cause different types of scattering, which affect how satellite imagery appears.</p>
