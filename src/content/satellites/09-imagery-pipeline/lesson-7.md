After processing the field, we can create borders around objects of interest, in this case field plots, to separate plots containing different genotypes, or treatments to analyze each plot.

<p>Within a plot, the vegetation index calculated for each pixel will be averaged with all pixels contained in a plot boundary. The calculated average value will be the vegetation index for that plot.</p>
